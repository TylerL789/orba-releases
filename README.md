# Orba — Downloads

Official releases of **Orba**, the floating sidebar HUD for macOS & Windows.

## Install

**macOS:** download the latest `Orba-x.x.x-arm64.dmg` from [Releases](https://github.com/TylerL789/orba-releases/releases), open it, drag Orba to Applications, then right-click → Open the first time (the app is not yet notarized).

**Windows:** download `Orba-Setup-x.x.x.exe` (installer) or `Orba-x.x.x-portable.exe` (no install needed).

Orba updates itself automatically once installed.
